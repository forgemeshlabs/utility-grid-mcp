# Security Policy

## Reporting a vulnerability

Please report security issues privately through GitHub's security advisory
feature for this repository. Do not open a public issue for a suspected
vulnerability.

Never include wallet private keys, payment signatures, API credentials, or
other secrets in reports, logs, screenshots, or example configuration.

## Wallet safety

Paid tools require a dedicated, low-balance Base wallet. Never use a primary
wallet. The three discovery tools work without any wallet configuration.
